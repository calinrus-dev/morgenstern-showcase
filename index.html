Generar no es entregar.

Del borrador al EPUB y al audiolibro hay estructura, revisión y archivos que deben abrirse. Esta muestra hace visible una parte concreta: inspeccionar una entrega sin tocar proveedores ni manuscritos.

Una entrega pequeña e inspeccionable

Descargar EPUB sintético

Un capítulo escrito para esta muestra. ZIP determinista, navegación y metadatos inspeccionables.

El audio es un tono de 440 Hz y un segundo. No es voz, ni un audiolibro generado con IA.

Informe con hashes SHA-256

Reproducir la entrega

python3 -m unittest discover -s test -v
python3 samples/delivery_demo.py
python3 samples/media_gate.py build/public-demo/tone.wav --minimum 0.9

Python 3.11+ y FFmpeg/ffprobe. Biblioteca estándar, sin paquetes Python. En Windows puedes usar py -3.

La puerta rechaza archivos vacíos, duración no finita, streams ausentes, resultados corruptos y procesos que exceden el tiempo límite.

Validación estructural acotada del EPUB. No equivale a una certificación EPUBCheck ni a verificar toda la producción editorial.
